# Assets

Every picture and sound in Plenty is generated by code in this repository. There are no image, audio or font files, so there's nothing to license and nothing to download.

| Asset | Where | Notes |
| --- | --- | --- |
| terrain, water, stellar core, remnant ground | `client/render.ts`, `ground()` | per-world palettes in `STAGES[].palette` (`shared/content.ts`); ground colour interpolates "dead" to "lush" by tile life |
| deposits (trees, rocks, dunes, ice, plasma, crystals, comets, galaxies) | `client/render.ts`, `deposit()` and helpers `tree`, `rock`, `crystal`, `galaxy` | chosen by world and resource family |
| buildings | `client/render.ts`, `building()`, `details()`, colours in `BUILD_LOOK` | extruded isometric boxes with per-type details (windows, chimneys, LEDs, drills, fins, masts, bunting, domes) |
| avatars | `client/render.ts`, `player()` | person, suit, drone, probe, wisp per `STAGES[].avatar`; colours in `PLAYER_COLOURS` |
| wildlife, dust devils, stars, sun glow, smoke, harvest pops | `client/render.ts`, `wildlife()`, `stars()`, `sunGlow()`, `effects()` | |
| emote glyphs | system emoji font | 👋 💛 😄 😮 😢 👉, drawn with `fillText` |
| interface | `app/globals.css` | system rounded sans (`ui-rounded`, falling back to `system-ui`) |
| music, ambience, effects | `client/audio.ts` | Web Audio oscillators and filtered noise: pentatonic (Earth, Mars) and minor (later worlds) plucks, a pad, birdsong chirps, wind/water noise, a machine hum, harvest/build/reject/transition tones |

## Replacing or extending them

- **A building's look**: add a `case` to `details()` and an entry in `BUILD_LOOK`. To use sprites instead, load an `Image` once and `drawImage` it at the building's centre in `building()`; depth sorting and occlusion fading already happen around that call.
- **A world's look**: edit its `palette` and the deposit branches keyed by `` `${stage.id}:${family}` `` in `deposit()`.
- **Sound**: `Sound` exposes `harvest()`, `build()`, `reject()` and `boundary()`; replace their bodies with `AudioBufferSourceNode`s playing decoded files routed to the same bus (`this.buses.effects`) to keep the volume controls working.
- **A renderer swap** (to PixiJS, say): `Renderer` is the only module that draws. It reads `GameClient.state` and the `View`, and exposes `pick()`, `facingTile()`, `target()` and `photo()` to the HUD.
